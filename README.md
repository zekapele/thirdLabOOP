# Лабораторна робота 3. Судоку

Android-застосунок для гри в судоку: генерація головоломки та перевірка розв’язку.

Мова: Java 17. Логіка гри не залежить від Android і покрита JUnit-тестами.

## Вимоги

1. Застосунок під Android на Java.
2. `java.util.logging.Logger`, рівні й формат задані у `sudoku-core/src/main/resources/logging.properties`.
3. Дві мови інтерфейсу: англійська та українська (`values/` і `values-uk/`). Перемикання — пункт меню на панелі.
4. Генерація судоку та перевірка розв’язку.

## Як грати

1. Оберіть складність: легко (42 підказки), середньо (34), важко (28).
2. Натисніть **Нова гра**. Поле будується так, щоб у головоломки лишився один розв’язок.
3. Оберіть клітинку й введіть цифру. Підказки змінити не можна. Повтор цифри в рядку, стовпці або квадраті 3×3 підсвічується.
4. **Перевірити** повідомляє, чи сітка ще не заповнена, чи є помилки, чи розв’язок правильний.
5. **Стерти** очищає вибрану клітинку. На емуляторі також працюють клавіші 1–9 і Backspace.

Кнопка мови показує мову, на яку відбудеться перехід. Поточна партія зберігається під час зміни мови.

## Логування

На пристрої журнал іде в Logcat з тегом `Sudoku`. Рівень пакета `thirdlab.sudoku` — `FINE`: старт генерації, кількість підказок, час, хід, результат перевірки, зміна мови.

```
2026-10-30 19:20:01 INFO thirdlab.sudoku.generator.SudokuGenerator - Generating puzzle, difficulty=MEDIUM, targetClues=34
2026-10-30 19:20:01 INFO thirdlab.sudoku.generator.SudokuGenerator - Puzzle ready, clues=34, removed=47, tookMs=180
```

Обробник створюється в коді, а не рядком у `logging.properties`: на Android `LogManager` шукає класи обробників системним завантажувачем і не бачить класи застосунку.

## Структура

```
sudoku-core/          правила, розв’язувач, генератор, партія, Logger
app/                  екран, поле, рядки uk/en, журнал у Logcat
```

Генератор заповнює повну сітку пошуком із поверненням, потім знімає клітинки (по можливості симетрично) і залишає зняття лише якщо розв’язок досі один.

## Збірка

Відкрийте теку в Android Studio і запустіть конфігурацію `app`.

Тести логіки:

```
./gradlew :sudoku-core:test
```
